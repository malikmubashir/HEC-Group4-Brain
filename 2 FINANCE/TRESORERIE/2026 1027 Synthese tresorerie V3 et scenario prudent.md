# Synthèse CFO — Trésorerie V3 et scénario prudent
Date : 27 octobre 2026. **Statut : scénarios provisoires, non validés par la Direction.**

## Cadre commun
Projet HEC Super Majordome IA ; aucune société créée à ce jour. Fondateurs non rémunérés pendant les 12 premiers mois (hypothèse de travail confirmée). Prévisionnel sur 36 mois. Prix Premium de travail 79 € TTC/mois, non validé commercialement.

## V3 central — résultats du modèle communiqué
- Point bas de trésorerie avant financement : **−172 798 €**.
- Réserve indicative : **40 500 €**.
- Enveloppe indicative : **213 298 €**.
- Trésorerie cumulée avant financement : fin A1 **−136 049 €** ; fin A2 **−127 339 €** ; fin A3 **+211 454 €**.
- Hypothèses : lancement M7 ; 150/800/2 500 abonnés actifs fin A1/A2/A3 ; CAC 150 € ; churn 3 % mensuel ; coût variable 18 € HT/client/mois ; MVP 77 050 € HT.
- V3 sépare facturation TTC, impayés, frais de paiement, TVA collectée/déductible, acquisition brute, churn, coûts variables, frais fixes et rémunérations.

## Scénario prudent — résultats du modèle communiqué
- Point bas de trésorerie avant financement : **−580 202 €**.
- Réserve indicative : **60 000 €**.
- Enveloppe indicative : **640 202 €**.
- Trésorerie cumulée avant financement : fin A1 **−176 100 €** ; fin A2 **−364 200 €** ; fin A3 **−580 200 €** (arrondis).
- Hypothèses : lancement M10 ; 60/350/1 100 abonnés actifs fin A1/A2/A3 ; CAC 240 € ; churn 5 % mensuel ; coût variable 26 € HT/client/mois ; MVP 100 000 € HT ; impayés 2 %.
- Le scénario prudent n'atteint pas l'équilibre de trésorerie cumulé à 36 mois.
