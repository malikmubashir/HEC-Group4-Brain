# Financement

Levées de fonds, prêts, subventions, table de capitalisation.

- Une note par sujet, nommée `AAAA MMJJ Titre.md`, sauf indication contraire ci-dessus.
- Un montant demandé n'est pas un montant obtenu : noter la pièce qui prouve les fonds reçus.
- Une table de capitalisation « après » une levée est une projection, pas un état.
