# Productions des assistants

Ce que les assistants IA produisent à la demande : notes de décision, synthèses, courriers préparés (jamais envoyés).

Une production n'est pas une source : elle s'appuie sur les documents de `sources/` et les cite. Une production n'est pas une décision : la décision est écrite par un humain dans le [[REGISTRE DES DECISIONS]].

Nom de fichier : `AAAA MMJJ Titre.md` (ex. `2026 1026 Note de décision.md`).
